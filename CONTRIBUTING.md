# Contributing

Thanks for your interest in improving this package.

## Workflow
1. Fork or create a branch from `master`.
2. Keep changes focused on one improvement or fix.
3. Add or update tests when behavior changes.
4. Run the test suite before opening a pull request.
5. Describe what changed and why in the pull request.

## Bug reports
Please include the Laravel/PHP versions, a minimal reproduction, expected behavior, and actual behavior.

## Pull requests
Prefer small, reviewable pull requests and avoid unrelated formatting changes.
